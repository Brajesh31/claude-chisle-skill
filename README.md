# Chisle

>

## Overview

This repository preserves the original AITMPL skill definition and its published companion files.

## Installation

```bash
git clone https://github.com/Brajesh31/claude-chisle-skill.git ~/.claude/skills/chisle
```

On Windows, use `%USERPROFILE%\.claude\skills\chisle` as the destination.

## Usage

Claude Code can load this skill when a request matches its description. Invoke directly with `/chisle` when needed.

## Repository structure

```text
chisle/
├── SKILL.md
├── LICENSE.txt
├── README.md
└── LICENSE
```

## Runtime requirements

- No build step is required for the instruction file.
- Review the original skill instructions before applying them.
- Any additional license notice included with the skill is preserved as a separate file.
